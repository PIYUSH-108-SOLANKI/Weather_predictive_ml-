1. Problem Definition & Formulation

Assigned Case Study 75: An environmental dataset contains historical observations, and the organization wants to identify meaningful patterns or estimate a selected future measure (With Proper Justification).

Formulated Machine Learning Task: Supervised Binary Classification to predict next-day rainfall (rain_tomorrow ∈ {0, 1}) across 8 meteorological stations in Maharashtra's 4 diverse agro-climatic sub-divisions (Konkan, Madhya Maharashtra, Marathwada, and Vidarbha). The target is defined as rain_tomorrow = 1 if next-day rainfall exceeds 0.0 mm (measurable rain), and 0 otherwise. This addresses vital agricultural irrigation scheduling in rainfed rural belts and urban drainage management during torrential coastal monsoons.

2. Dataset & Preprocessing Pipeline

Data Source: 25 consecutive years (1 January 2000 – 31 December 2024, 73,056 records) of daily and hourly reanalysis data acquired from ECMWF ERA5 via the Open-Meteo Historical API across Mumbai, Ratnagiri, Pune, Nashik, Kolhapur, Solapur, Chhatrapati Sambhajinagar, and Nagpur. Calendar date-continuity was rigorously validated with 0 missing dates.

35-Feature Engineering Schema: Incorporates 1, 3, and 7-day temporal lags for precipitation, temperature, humidity, and barometric pressure; trailing 3-day and 7-day rolling aggregates (cumulative rainfall and running means); cyclical Fourier calendar projections (month_sin/cos, doy_sin/cos); and domain categoricals (IMD seasons, WMO codes, stations).

Chronological Validation: Data was split chronologically to strictly avoid temporal leakage: Train Set: 2000–2022 (67,208 records, 92%), Validation Set: 2023 (2,920 records, 4%), and Held-out Test Set: 2024 (2,928 records, 4%).

3. Model Experiments & Held-Out Test Set (2024) Benchmarks

Three supervised algorithm families were developed and hyperparameter-tuned on the validation split, then benchmarked on the held-out 2024 test year:

Champion Model Selection Justification: Tuned Gradient Boosting delivered the highest test ROC-AUC (0.9714) and F1-score (0.8593), and the lowest Brier score (0.0682, indicating superior probability calibration). Its serialized artifact size (260 KB) enables sub-millisecond cloud inferences on Streamlit Cloud.

4. Interactive Streamlit Application

The cloud-hosted application is active at https://weatherpredictiveml-git-geavtut3pfyypewaut2she.streamlit.app/ and provides:

  • Live Real-Time Forecast: Queries live Open-Meteo telemetry across 8 Maharashtra stations with 7-day atmospheric trend charts (temperature swings, humidity build-up, and rainfall history) and IMD advisory warnings.
  • What-If Scenario Simulator: Interactive offline sliders to stress-test model behavior under extreme monsoon downpours, scorching dry summers, and winter conditions.
  • Multi-Model Comparison: Evaluates inputs across Gradient Boosting, Random Forest, and Logistic Regression side-by-side with individual probabilities and consensus agreement.
  • Decision Threshold Slider: Customizable probability cutoff (0.10 to 0.90) demonstrating operational precision-recall trade-offs.
